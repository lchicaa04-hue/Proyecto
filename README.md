# Proyecto Tú y Yo

Repositorio principal del proyecto académico y de producción del cortometraje animado 3D **Tú y yo**.

## Estructura

- `docs/` — concepto, narrativa, guion, cronograma y documentación.
- `blender/` — modelado, UVs, materiales, rig y animación 3D.
- `unity/` — prototipos interactivos, UI, escenas y gameplay.
- `assets/` — recursos compartidos, referencias y audio.
- `renders/` — renders, pruebas y entregables visuales.

## 🎯 Propósito

Observar la perspectiva de un joven que vive bajo la presión constante de las expectativas sociales y personales, enfrentándose a una realidad en la que vivir se ha vuelto más complejo de lo que alguna vez imaginó.”
